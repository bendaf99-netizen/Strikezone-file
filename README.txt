STRIKEZONE FPS — Android project starter

This is an Android Studio project source, not a precompiled APK.
It contains a mobile-friendly 3D FPS prototype in a WebView.

Build:
1. Install Android Studio on a computer.
2. Open this folder as a project.
3. Let Gradle sync.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Install the resulting APK on your Android phone.

Notes:
- The 3D engine is loaded from a CDN, so the first launch requires internet.
- This is a prototype, not a finished commercial-quality shooter.
- Start with medium/low settings on phones for better performance.
